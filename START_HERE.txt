📋 2 STEPS TO START:

┌─────────────────────────────────────────────────────────────────────┐
│ STEP 1: Create Database Tables (ONE TIME - 2 minutes)              │
└─────────────────────────────────────────────────────────────────────┘

1. Open this URL in your browser:
   https://supabase.com/dashboard/project/dtcwjaunekcbnrtshgok/sql/new

2. Open this file:
   server\setup-database.sql

3. Copy ALL the SQL from that file

4. Paste into Supabase SQL Editor

5. Click "RUN" button (or press Ctrl+Enter)

6. You should see: "Database setup completed successfully!" ✅


┌─────────────────────────────────────────────────────────────────────┐
│ STEP 2: Start the Application                                      │
└─────────────────────────────────────────────────────────────────────┘

Open a terminal in this directory and run:

   npm run dev

The app will start on:
   → Backend:  http://localhost:3001
   → Frontend: http://localhost:3000

Open your browser to: http://localhost:3000
